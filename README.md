# DUO Wallpapers — sito per iPhone Duo

Sito pubblico: https://simonedevittori.github.io/Duo-Wallpaper/

24 sfondi disponibili direttamente nel sito: 20 originali in `originals/` e 4 sfondi DUO Studio in `assets/`. Anteprime e download non richiedono Google Drive. Tutti gli originali sono conservati senza ridimensionamento.

GitHub Pages pubblica il ramo `main` dalla radice. Il sito offre ricerca, filtri, preferiti locali e tema chiaro/scuro. Le risoluzioni effettive sono indicate nelle schede degli sfondi.

Per aggiungere uno sfondo, carica il file in `originals/` e aggiungi una voce in `wallpapers.json` con id, title, category, image, source, filename, width e height.

Concept indipendente non affiliato ad Apple.
